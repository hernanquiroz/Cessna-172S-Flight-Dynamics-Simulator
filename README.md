# Cessna 172S Flight Dynamics Simulator

Simulador de dinámica de vuelo basado en datos reales del Pilot's Operating Handbook (POH) del Cessna 172S.

## 🎯 Características

- **Modelo físico real**: Ecuaciones de sustentación, arrastre, peso y empuje
- **Datos del POH**: Especificaciones reales del Cessna 172S
- **Tablero interactivo**: Indicadores tipo cabina
- **Gráficas en tiempo real**: Visualización de fuerzas y performance
- **Deploy en Streamlit Cloud**: Listo para GitHub

## 🚀 Instalación Local

```bash
git clone https://github.com/tu-usuario/cessna-172s-simulator.git
cd cessna-172s-simulator
pip install -r requirements.txt
streamlit run app.py
